# Billionaire Gang Website

A modern, cinematic, and responsive fan-made/personal project website inspired by **Billionaire Gang**. The site is designed to showcase BG's brand identity, latest YouTube content, creator profile, social links, and core influence network using a dark luxury theme with gold accents.

![Billionaire Gang Website Preview](./public/images/preview.png)

---

## 🚀 Live Demo

**Website:** https://billionaire-gang.vercel.app

---

## 📌 About the Project

This project is a personal web design and development build created for the **Billionaire Gang** brand concept. The website focuses on presenting BG as a premium creator group through strong typography, bold visuals, smooth animations, and a luxury-inspired black-and-gold interface.

The goal of this project is to create a professional-looking landing page that feels like an official creator website, while also functioning as a content hub for videos, members, social links, and brand information.

---

## ✨ Features

- Hero section with strong Billionaire Gang branding
- Latest video/drop highlight
- YouTube-inspired content library
- Video category filters such as vlogs, challenges, announcements, and giveaways
- Creator/founder profile section
- Social media link buttons
- Animated UI elements and hover effects
- Responsive layout for desktop and mobile screens
- Premium dark theme with gold highlights
- Smooth transitions and modern web design styling

---

## 🖼️ Website Sections

### 🏆 Hero Section

The homepage introduces the brand with a bold **BILLIONAIRE GANG** title, founder information, CTA buttons, and channel statistics such as subscribers, videos, and views.

### 🎬 Content Library

A dedicated section for displaying the latest videos from Billionaire Gang. Each content card includes a thumbnail, title, views, likes, date, and action buttons for watching or opening on YouTube.

### 👑 BG Directory / Core Influence

This section highlights the founder and key personalities connected to the brand. It includes social media buttons, subscriber statistics, and a clean profile layout.

## 🛠️ Tech Stack

This project was built using:

- **Next.js** – React framework for building the website
- **React** – Component-based UI development
- **TypeScript** – Type-safe development
- **Tailwind CSS** – Utility-first styling
- **Framer Motion** – Smooth animations and transitions
- **Vercel** – Deployment and hosting

## 🎨 Design Concept

The design uses a **luxury digital creator aesthetic**, combining:

- Deep black backgrounds
- Gold accent colors
- Large bold typography
- Minimal but premium spacing
- Subtle grid textures
- Clean video cards
- Creator-focused presentation

The visual direction aims to make the website feel bold, exclusive, and entertainment-driven while still being simple and easy to navigate.

---

## 📱 Responsiveness

The website is designed to work across different screen sizes, including:

- Desktop monitors
- Laptops
- Tablets
- Mobile phones

Layouts, cards, text sizes, and spacing are adjusted to maintain readability and visual balance across devices.
